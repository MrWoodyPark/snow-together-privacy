기기에 저장하는 정보

선택한 이름(최대 5글자)과 캐릭터를 기기 내부에 저장합니다. 계정 가입을 요구하지 않습니다. 앱을 삭제하면 기기 내 저장 정보도 삭제됩니다.

같은 Wi-Fi에서 함께하기

로컬 네트워크 권한은 Bonjour 방 검색과 방 참가에 사용합니다. 이름·캐릭터·이동·조준·눈덩이·HP·점수 등 게임 상태는 방 참가자 사이에 공유됩니다. 방장 기기가 일시적으로 경기 판정과 동기화를 담당하며, 경기는 메모리에서 처리됩니다. 개발자가 운영하는 수집 서버로 전송하지 않습니다. 위치 또는 Wi-Fi 이름(SSID)을 수집하지 않습니다.

통신과 권한

로컬 TCP 통신에 앱 자체의 TLS 암호화나 방 비밀번호는 없습니다. 신뢰할 수 있는 Wi-Fi에서 사용해 주세요. 같은 네트워크의 앱 사용자에게 방 이름이 표시되며 대기 중인 방에 참가할 수 있습니다. 로컬 네트워크 권한을 거부해도 혼자 연습할 수 있습니다. 설정에서 권한을 변경할 수 있습니다.

광고·분석·외부 서비스

앱에 광고·분석 SDK·추적 기능은 없습니다. 개발자는 플레이 기록이나 개인정보를 서버에 보관하지 않습니다. 이 정책·지원 웹사이트는 GitHub Pages에서 제공되므로 웹사이트 방문 시 GitHub가 IP 주소 등 접속 정보를 처리할 수 있습니다. GitHub 개인정보 안내를 참고해 주세요.
